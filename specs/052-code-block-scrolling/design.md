# Design — Bounded code-block scrolling

Approval: approved on 2026-10-16 by the user instruction to implement the supplied “Publish QMarkdown 1.11, then implement 1.12 code-block usability” plan. Scope includes Features 050–053 and one package 1.12.0 / QML 1.12 release PR. Merge, tagging and publication of 1.12 require separate authorization.

Use a clipped Qt Quick viewport with reserved scrollbar gutters and no Controls dependency. Instantiate filtered host scrollbar properties per overflowing axis, with native fallback. Preserve the first visible source position across layout changes, clamp offsets, reset horizontal offset for wrap and both for source replacement. Wheel/touch boundary handoff and desktop selection priority. Reveal Find internally before outer navigation, suppress navigation snapback after manual scrolling. Extend clipped hit testing and selection edge scrolling.

The source WheelHandler owns both angle and phased pixel wheel movement. A private event filter skips native Flickable wheel handling for unconsumed source events: its phased pixel path otherwise consumes boundary events. Mouse selection disables source Flickable interaction; a touchscreen-only drag handler retains panning and reports vertical remainder outward. Plain Text uses a single view-owned cached QTextLayout only when source-anchor geometry is queried; default unscrolled plain blocks avoid that extra layout.
