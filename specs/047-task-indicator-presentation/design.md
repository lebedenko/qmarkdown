# Design

Approved on 2026-10-15 by the user instruction to implement the supplied plan. Approval covers the stated requirements, design, tasks and verification; release publication is excluded.

MarkdownView passes the component through its recursive BlockSequence factory into ListBlock. Task rows alone instantiate a private TaskIndicatorHost. The host schedules creation outside binding evaluation, invalidates old instances immediately, and creates trusted components with live checked/style bindings, invalidates a creation token on replacement and destroys obsolete instances. A private QQuickPaintedItem supplies fallback artwork without Controls. Preferred dimensions are individually validated; actual artwork geometry remains natural while the host clips at narrow widths. The first text line and indicator share the taller first-line band; row height includes the shifted content and indicator.

The host exposes the sole accessible checkbox (checked, read-only, unfocusable, no activation) through a focused public-Qt QAccessibleObject implementation. This is necessary because Qt Quick otherwise advertises Toggle/Press even for a read-only checkbox. QML attached accessibility continues to mark the item in the scene tree and send state notifications; the private interface supplies parent/geometry/state and exposes no action interface. Custom artwork is contractually decorative; application code is trusted rather than sandboxed. The viewer reparents the public indicator of a hidden, enabled CheckBox into a decorative Item, binding palette and checked state. Generic Controls imports select the active style.
